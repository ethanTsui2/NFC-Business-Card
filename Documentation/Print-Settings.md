# Print Settings

These are the project settings used while developing the card.

## Printer

- **Printer:** Bambu Lab A1
- **Nozzle:** 0.2 mm
- **Material:** PLA
- **Base profile:** Bambu 0.10 mm Standard for A1 / 0.2 mm nozzle
- **Front surface:** face-down on a holographic/effect plate

## Geometry

- Card size: approximately **85.6 x 54 mm**
- Final thickness target: **1.6 mm**
- Earlier prototypes: **0.8 mm**
- Corner radius: approximately **3 mm**

## First-Layer Graphics

The front graphics are viewed from the build-plate side. I used Preview to make sure the white graphics only extended as deep as needed, which reduced unnecessary filament changes and purge waste.
