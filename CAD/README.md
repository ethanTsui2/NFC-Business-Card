# CAD

This folder is for the final card CAD and manufacturing geometry.

## Design Targets

- 85.6 x 54 mm overall size
- approximately 3 mm corner radius
- approximately 1.6 mm thickness
- internal NFC cavity
- face-down front graphics
- QR code on the back

## Recommended Files

When finalized, this folder should contain:

- native CAD source
- STEP export
- STL or 3MF export
- clean screenshot of the final card
