# Print Files

This folder is for the final slicer/project files.

Recommended files:

- Bambu Studio `.3mf`
- final STL/STEP export
- NFC-pause test version
- small first-layer calibration coupon

Before printing, verify:

- 0.2 mm nozzle
- correct filament assignments
- correct first-layer graphics
- clean QR code
- NFC pause while the cavity is still open
