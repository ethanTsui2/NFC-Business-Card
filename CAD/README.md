# CAD

This folder is for the final card CAD and manufacturing geometry.

## Final Design Specifications

- 85.6 x 54 mm overall size
- approximately 3 mm corner radius
- 0.8 mm overall thickness
- internal NFC cavity
- face-down front graphics
- QR code on the back

The earlier 1.6 mm design is superseded. Check the actual NFC tag thickness, cavity depth, and remaining PLA above and below the tag in the 0.8 mm geometry. Do not reuse the thicker card's pause height without checking the sliced model. The final cavity dimensions are not recorded here.

## Recommended Files

When finalized, this folder should contain:

- native CAD source
- STEP export
- STL or 3MF export
- clean screenshot of the final card
